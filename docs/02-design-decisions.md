# Design decisions

Noah is creative director and lead UX. Every product decision is logged here with its status.

- **Approved:** Noah decided it, or signed off on it.
- **Proposed:** Claude suggested it in the v0 prototype, and it's waiting for Noah's review.
- **Open:** not decided yet.

Claude Code should build Approved items as written, build Proposed items as placeholders that are easy to change, and ask before building anything Open.
